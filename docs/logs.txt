8. AI SYSTEM DESIGN
-------------------
The AI logic is one of the central features of the project.

Primary implementation:
- src/chatbot/dual_ai_client.py

This client uses:
- Gemini as the primary AI system
- Granite AI as a fallback
- a rule-based emergency fallback when both fail

The system is intentionally built to be robust so the app still provides a financial response even if advanced AI is unavailable.

The core flow is:
1. Try Gemini first
2. If Gemini fails or returns an unusable result, fall back to Granite
3. If Granite fails, return a generic but still helpful finance advice response

This is visible in DualAIClient.get_response().
